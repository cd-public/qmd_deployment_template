# qmd_deployment_template
In theory, this will be a page that has an edittable MD and some infrastructure that can be used a basis of stand-alone, edittable websites without a local quarto install.

Prompted as:

```
Add a ".github/workflows/deploy.yml" that will take "index.md" from top level (create a demo "hello world" index.md as well to demonstrate) and render the .md to .html using quarto, then deploy the html file via static site builder to github pages.
```
